# TSK-07. Why Scout made this task

- **Audience:** CLs, techs and doctors.
- **Length:** 1½ minutes.
- **Watch first:** TSK-01.
- **Signed in as:** Jordan Pike (technician).
- **The one thing to remember:** do the work, and the task closes itself. Marking a chart, bill or lab task done while the work is still open just brings it back.

## Why (opening)

"Scout watches for work that slipped: a chart left unsigned, a bill left open, a call never filed. It turns what's still undone into a task for the right person, so nothing quietly falls through."

## What else you can do here

- The seven rules: unfinished charts, open bills, calls not filed, labs with no results, order-list items, failed membership signups, and the weekly Vet Snap upload (Settings → Automatic Tasks, TSK-13). Who gets each: the doctor on the visit, whoever put the first charge on the bill, whoever made the call, whoever charged the lab, the office's Inventory Manager, the client liaison queue, the practice manager.

- Each automatic task has its own video: TSK-08 (charts), TSK-09 (bills), TSK-10 (calls), TSK-11 (labs), TSK-12 (order list and Vet Snap). Failed membership signups are in MEM-21.
- Automatic tasks can be moved or removed like any other (TSK-04, TSK-05).
- Which ones come back after an early Mark done is a per-rule setting ("Comes back if they mark it done but the work is not"). Today that's charts, bills, labs and the order list; calls, signups and Vet Snap stay closed.

## What other roles see

- Same for every role. Practice managers can read the rules in Settings → Automatic Tasks (TSK-13).

## Closing

"The most common mistakes: clicking Mark done without doing the work, which only brings the task back at the next check, and ignoring a task because a computer made it. Remember: do the work, and the task closes itself."
