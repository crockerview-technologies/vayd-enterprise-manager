# TSK-13. Settings → Automatic Tasks: read the rules, and spot a problem

- **Audience:** managers.
- **Length:** 2½ minutes.
- **Watch first:** TSK-07.
- **Signed in as:** Dr. Avery Lane's admin login (the practice owner); Robin Hale (practice manager) for step 18.
- **The one thing to remember:** a red **Last run hit a problem** line means that rule stopped partway. Tell the admin the same day.

## Why (opening)

"Seven rules chase unfinished work for the whole practice. A manager checks them now and then, and especially in the first week after go-live, to make sure they're running."

## What else you can do here

- **Day of the week** and **Time (Eastern)** on the weekly Vet Snap rule.
- **Limit to one office**, **Due**, and **Who else should see it** on every rule.
- **Last checked** (bottom of an open rule) shows the rule's last run.

## What other roles see

- Practice managers: read-only list with each rule's task wording (Settings → Practice → Automatic Tasks).
- Other staff don't see this page.

## Closing

"The most common mistakes: switching a rule off to quiet a busy task list, and scrolling past a red problem line. Remember: a red Last run hit a problem line means that rule stopped partway. Tell the admin the same day."
