# TSK-10. "File the call with …": a call never filed

- **Audience:** CLs, techs and doctors.
- **Length:** 1½ minutes.
- **Watch first:** TSK-07; the Quo calls Help topic.
- **Signed in as:** Casey Morgan (client liaison).
- **The one thing to remember:** file the call, or click **Don't file**. Either one closes the task straight away.

## Why (opening)

"Every call Quo transcribes has to be filed or waved off, so the record shows what we told the family. If a call is still unfiled at six p.m., whoever made it gets a task."

## Steps

Once B2 is fixed, steps 4 and 5 become: open the task, and file the call from it.

## What else you can do here

- **Open client** on the dock jumps to the client's page.
- **Clean up again** and **Show verbatim** switch between the tidied note and the raw transcript.

## What other roles see

- The task goes to whoever placed or answered the call; with nobody known, it waits on the Practice Manager queue.
- The call rule doesn't bring a task back after it's closed, and never looks before the go-live date (D1, TA-03).
- Everyone can file a call to the pet's chart as a communication note, or client-only.

## Closing

"The most common mistakes: letting calls pile up in the dock, and calling the family again because the task looked like a new callback. Remember: file the call, or click Don't file. Either one closes the task straight away."
